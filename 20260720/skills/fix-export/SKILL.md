# 导出数据不一致排查与修复

> **触发场景**：页面查询结果与 Excel 导出结果不一致（行数不同、字段缺失、数据错误）
> **高频根因**：导出方法与列表查询方法是**独立代码路径**，导出方法缺少条件清理、字段映射或单位换算

## 核心流程

```text
定位导出方法 → 并排对比 SQL → 定位差异 → 修复导出方法 → 验证
```

---

## 第 1 步：定位导出方法（禁止假设）

**导出方法 ≠ 列表查询方法**，必须分别追踪。

1. **grep 前端导出按钮的 axios URL**（不是列表查询 URL）
   ```bash
   # 在前端 views 目录搜索导出相关关键词
   grep -rn "export\|download\|导出" src/pages/index/views/模块目录/ --include="*.vue"
   ```
2. 追踪该 URL → Controller 方法 → Service 方法 → Mapper XML
3. **输出**：导出方法的完整调用链（文件路径 + 行号）

### 禁止行为

- ❌ 假设页面查询方法就是导出方法
- ❌ 只 grep 后端 Controller 而不从前端 URL 开始追踪
- ❌ 找到一个方法就直接修复，不确认是否是导出调用的方法

---

## 第 2 步：并排对比 SQL

将导出方法与列表查询方法的 SQL **逐行对比**：

| 对比维度 | 检查点 |
|----------|--------|
| WHERE 条件 | 导出方法是否缺少过滤条件（权限、状态、组织范围） |
| JOIN 表 | 导出方法是否少了 LEFT JOIN 或多了 JOIN 导致行数变化 |
| GROUP BY | 分组字段是否一致，不一致会导致行数差异 |
| SELECT 字段 | 导出方法是否缺少需要的字段（如 ratio、unit_price） |
| 排序 | ORDER BY 是否一致 |
| 数据转换 | Service 层是否有额外的过滤、聚合或字段映射 |

### 数据库验证

```sql
-- 分别执行导出 SQL 和列表 SQL，对比结果集
-- 1. 执行列表查询 SQL，记录行数
-- 2. 执行导出 SQL，记录行数
-- 3. 差集分析：找出哪些行在一方存在另一方不存在
SELECT * FROM (列表SQL) a WHERE a.id NOT IN (SELECT id FROM (导出SQL) b);
```

---

## 第 3 步：定位差异根因

### 常见差异模式

| 模式 | 根因 | 修复方向 |
|------|------|---------|
| 行数不一致 | 导出方法缺少 WHERE 条件 | 在导出方法补齐缺失的过滤条件 |
| 字段为空 | 导出 SQL 未查询该字段 | 在 SELECT 中添加缺失字段 |
| 金额错误 | 单位换算缺失（基础单位 × 采购单价） | 添加 ratio 换算或使用正确的单价字段 |
| 数据重复 | LEFT JOIN 导致一对多行膨胀 | 改用子查询或 DISTINCT |
| 权限差异 | 导出方法未应用数据权限过滤 | 对齐列表查询的权限条件 |

### 单位换算专项（仓储模块）

> 详细域知识见 CLAUDE.md §8.1 和 `docs/superpowers/specs/2026-07-16-物料管理模块业务逻辑说明.md`

导出涉及数量和金额时，必须确认：
- `IN_NUM` / `NUM` 存储的是**基础单位**数量
- `UNIT_PRICE` 存储的是**操作单位**（采购/入库单位）单价
- 总价 = **操作单位数量 × 操作单位单价**（不是基础单位数量 × 操作单位单价）
- 换算：`操作单位数量 = 基础单位数量 ÷ ratio`

---

## 第 4 步：修复

- **仅修改导出方法**，不修改列表查询方法（除非两边都有 Bug）
- 最小 diff：只补齐缺失的条件/字段/换算逻辑
- 修复后检查：grep 同模块其他导出方法，排查同类问题

---

## 第 5 步：验证

1. 执行修复后的导出 SQL，对比列表查询 SQL 结果集
2. 行数一致、字段完整、金额正确
3. 检查同模块其他页面是否有相同的导出差异模式

---

## 常见陷阱

- 修了查询方法但导出问题依旧（导出是独立代码路径）
- 只修一个页面的导出，遗漏同模块其他页面
- 单位换算时用基础单位数量乘以操作单位单价（单位不匹配）
- 修完不验证 SQL 结果集就声称完成

---

## 交付要求

- 导出方法与列表方法的调用链对比
- SQL 差异点（文件路径 + 行号）
- 修复内容和影响范围
- 验证结果（行数对比、SQL 执行结果）
- 同模块其他导出方法的排查结果
